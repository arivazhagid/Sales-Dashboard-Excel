# Sales Dashboard (Excel)

This project contains a simple sales dashboard created using Microsoft Excel.  
It includes:

- Pivot Tables to summarize sales by salesperson, region, and product
- Visual charts (bar, pie, line) to show sales trends
- Real-world scenario to practice Excel data analysis skills

## Tools Used:
- Microsoft Excel
- PivotTables
- PivotCharts

## Skills Applied:
- Data cleaning
- Data visualization
- Dashboard design
